# Risks

## Platform Risks

- Fabric trial expires after 60 days.
- Trial capacity does not reflect enterprise networking capabilities such as Private Link.
- Some Fabric admin or networking APIs are preview or have partial coverage.
- Workspace sprawl can happen quickly without strong naming and ownership rules.

## Control Actions

- record trial start and expiration dates
- use group-based access from day 1
- keep all non-secret platform configuration in source control
- prefer API-driven automation where supported
